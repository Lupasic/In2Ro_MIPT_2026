# Open Sans font provenance

These static Open Sans 2.1 TrueType files are copied from the local TeX Live 2026 `opensans` package so that course decks compile reproducibly without relying on operating-system font registration.

- Typeface designer: Steve Matteson.
- TeX Live package: `opensans`, version 2.1.
- Original font license: Apache License 2.0.
- Included license: `LICENSE-APACHE-2.0.txt`.
- Included package statement: `TEXLIVE-README.txt`.

Deck-local copies must preserve both license files. The original slide templates remain unchanged; production decks load these files by filename from their local `fonts/open-sans/` directory.
